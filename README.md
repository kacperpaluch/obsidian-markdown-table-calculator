# Markdown Table Calculator

Obsidian plugin that automatically calculates formulas in Markdown tables.

## Installation

### Option A — Manual

1. Download `main.js`, `manifest.json`, and `styles.css` from the [latest release](https://github.com/kacperpaluch/obsidian-markdown-table-calculator/releases/latest).
2. Create a folder inside your vault:

```text
<Vault>/.obsidian/plugins/markdown-table-calculator/
```

3. Copy the three downloaded files into that folder.
4. Reload Obsidian and enable **Markdown Table Calculator** in **Settings → Community plugins**.

### Option B — BRAT

1. Install the [BRAT](https://github.com/TfTHacker/obsidian42-brat) community plugin.
2. In BRAT settings click **Add Beta plugin** and enter:

```
kacperpaluch/obsidian-markdown-table-calculator
```

3. Enable **Markdown Table Calculator** in **Settings → Community plugins**.

## Usage

Add a formula to a table cell:

```md
| Item   | Amount |
|--------|-------:|
| Apples | 10     |
| Fuel   | 50     |
| Lunch  | 22,32  |
| Total  | =SUM   |
| Avg    | =AVERAGE |
| Count  | =COUNT |
| Min    | =MIN   |
| Max    | =MAX   |
```

After a short pause, the plugin updates the formula cells:

```md
| Total  | <span class="markdown-table-calculator-positive">82,32</span> <!-- table-calc: SUM --> |
| Avg    | <span class="markdown-table-calculator-positive">27,44</span> <!-- table-calc: AVERAGE --> |
| Count  | 3 <!-- table-calc: COUNT --> |
| Min    | 10 <!-- table-calc: MIN --> |
| Max    | 50 <!-- table-calc: MAX --> |
```

The hidden HTML comment keeps the formula in the Markdown file, so future edits to the column are recalculated automatically. Positive results are green and negative results are red in rendered Markdown.

You can reference a column by:

- current column: `=SUM`
- header name: `=SUM(Amount)`
- 1-based column number: `=SUM(2)`
- spreadsheet-style letter: `=SUM(B)`

## Supported formulas

| Formula | Aliases | Description |
|---------|---------|-------------|
| `SUM` | — | Sum of all numeric values in the column |
| `AVERAGE` | `AVG` | Arithmetic mean of values |
| `COUNT` | — | Number of numeric values (no decimal places) |
| `MIN` | — | Smallest value in the column |
| `MAX` | — | Largest value in the column |

Column references work the same for all formulas:

- `=SUM` / `=AVERAGE` / `=COUNT` / `=MIN` / `=MAX` — operates on current column
- `=AVERAGE(Amount)` — targets column by header name
- `=COUNT(2)` — targets column by 1-based number
- `=MIN(B)` — targets column by spreadsheet letter

After a formula is calculated, the plugin stores it in an HTML comment:

```md
<!-- table-calc: AVERAGE -->
```

This keeps the formula available for future recalculations while showing the calculated value in the table.

## Settings

Open the plugin settings in Obsidian to see the usage instructions and configure:

- automatic recalculation
- debounce delay
- decimal places
- decimal separator
- thousands separator
- result suffix, for example ` zł`

## Limitations

- Only Markdown tables are supported.
- Only column-based formulas are supported — no cell ranges or row formulas.
- Cell ranges such as `B2:B10` are not supported.
- Formulas across multiple tables are not supported.
- Number parsing is heuristic and supports common comma, dot, and space-separated formats.

## Development

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Release

Releases are published from Git tags. The tag must match `manifest.json` and `package.json`.

To publish a new release:

```bash
npm version patch      # bump version in manifest.json, package.json, versions.json
npm run build           # produces main.js
git push origin main --follow-tags
```

Then go to the [Releases](https://github.com/kacperpaluch/obsidian-markdown-table-calculator/releases) page, click **New Release**, select the tag, and attach `main.js`, `manifest.json`, and `styles.css`.

Do not commit `main.js`; it is generated by the build step.
