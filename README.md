# Markdown Table Calculator

Obsidian plugin that automatically calculates `SUM` formulas in Markdown tables.

## Installation

### Install with BRAT

1. Install the [BRAT](https://github.com/TfTHacker/obsidian42-brat) plugin in Obsidian.
2. Open the command palette and run **BRAT: Add a beta plugin for testing**.
3. Enter this repository:

```text
kacperpaluch/obsidian-markdown-table-calculator
```

4. After BRAT installs the plugin, open **Settings → Community plugins**.
5. Refresh the plugin list and enable **Markdown Table Calculator**.

### Manual install

1. Download `main.js`, `manifest.json`, and `styles.css` from the latest GitHub release.
2. Copy the files into your vault:

```text
<Vault>/.obsidian/plugins/markdown-table-calculator/
```

3. Reload Obsidian and enable **Markdown Table Calculator** in **Settings → Community plugins**.

## Usage

Add a formula to a table cell:

```md
| Item | Amount |
|---|---:|
| Groceries | 10 zł |
| Fuel | 50 zł |
| Lunch | 22,32 zł |
| Total | =SUM |
```

After a short pause, the plugin updates the formula cell:

```md
| Total | <span class="markdown-table-calculator-positive">82,32 zł</span> <!-- table-calc: SUM --> |
```

The hidden HTML comment keeps the formula in the Markdown file, so future edits to the column are recalculated automatically. Positive sums are green and negative sums are red in rendered Markdown.

You can reference a column by:

- current column: `=SUM`
- header name: `=SUM(Amount)`
- 1-based column number: `=SUM(2)`
- spreadsheet-style letter: `=SUM(B)`

## Supported formulas

The plugin currently supports `SUM` formulas only:

- `=SUM`
- `=SUM(Amount)`
- `=SUM(2)`
- `=SUM(B)`

After a formula is calculated, the plugin stores it in an HTML comment:

```md
<!-- table-calc: SUM -->
```

This keeps the formula available for future recalculations while showing the calculated value in the table.

## Settings

Open the plugin settings in Obsidian to see the usage instructions and configure:

- automatic recalculation
- debounce delay
- decimal places
- decimal separator
- thousands separator
- result suffix, for example ` zł`

## Limitations

- Only Markdown tables are supported.
- Only column-based `SUM` formulas are supported.
- Cell ranges such as `B2:B10` are not supported.
- Row formulas and formulas across multiple tables are not supported.
- Number parsing is heuristic and supports common comma, dot, and space-separated formats.

## Development

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
```

## Release

Releases are published from Git tags. The tag must match `manifest.json` and `package.json`.

To publish a new release:

```bash
npm version patch
git push origin main --follow-tags
```

The release workflow builds the plugin, validates that the tag matches `manifest.json`, and uploads these assets:

- `main.js`
- `manifest.json`
- `styles.css`

Do not commit `main.js`; it is generated by the release workflow and attached to GitHub Releases for BRAT.
